# Code for Publication

[简体中文](README.md) | **English**

This repository collects simulation code for research and metrology projects. Each project has its own folder. Select a project heading to open its folder, or select a source file to view it directly.

## Project folders

### [NO1 High Frequency Electrosurgical Units](https://github.com/TangXun1990/code-for-publication/tree/main/NO1%20High%20Frequency%20Electrosurgical%20Units)

MATLAB R2018b simulation of uncertainty in the indicated output-power error of high-frequency electrosurgical units.

Main source: [MCM](https://github.com/TangXun1990/code-for-publication/blob/main/NO1%20High%20Frequency%20Electrosurgical%20Units/HighFrequencyElectrosurgicalUnits202601.m) · [Dependencies in this folder](NO1%20High%20Frequency%20Electrosurgical%20Units/README.md)

### [NO2 Linear Accelerator](https://github.com/TangXun1990/code-for-publication/tree/main/NO2%20Linear%20Accelerator)

MATLAB R2024b simulation of uncertainty in absorbed dose to water from a linear accelerator.

Main sources: [GUM method](https://github.com/TangXun1990/code-for-publication/blob/main/NO2%20Linear%20Accelerator/NO2linearacceleratorGUM.m) · [MCM method](https://github.com/TangXun1990/code-for-publication/blob/main/NO2%20Linear%20Accelerator/NO2linearacceleratorMCM.m) · [Dependencies in this folder](NO2%20Linear%20Accelerator/README.md)

### [NO3 Ventilator Tidal Volume](https://github.com/TangXun1990/code-for-publication/tree/main/NO3%20Ventilator%20Tidal%20Volume)

Python 3.12.9 simulation of uncertainty in the relative indication error of ventilator tidal volume.

Main sources: [Correlation analysis](https://github.com/TangXun1990/code-for-publication/blob/main/NO3%20Ventilator%20Tidal%20Volume/Correlation.py) · [MCM method](https://github.com/TangXun1990/code-for-publication/blob/main/NO3%20Ventilator%20Tidal%20Volume/MCM.py) · [Dependencies in this folder](NO3%20Ventilator%20Tidal%20Volume/README.md)
