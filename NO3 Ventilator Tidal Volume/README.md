# NO3 呼吸机潮气量 | Ventilator Tidal Volume

## 简体中文

### 项目依赖

- Python 3.12.9。
- `Correlation.py`：NumPy 2.4.2、Matplotlib 3.10.8、pandas、tqdm、openpyxl。
- `MCM.py`：NumPy 2.4.2、Matplotlib 3.10.8、SciPy 1.17.1、Numba 0.64.0。
- pandas、tqdm 和 openpyxl 的版本未在仓库中注明。
- 图中中文显示还取决于系统是否安装脚本配置的中文字体；字体不属于 Python 包依赖。

### 主要文件

- [Correlation.py](Correlation.py)：相关性分析。
- [MCM.py](MCM.py)：蒙特卡洛分析。

## English

### Dependencies

- Python 3.12.9.
- `Correlation.py`: NumPy 2.4.2, Matplotlib 3.10.8, pandas, tqdm and openpyxl.
- `MCM.py`: NumPy 2.4.2, Matplotlib 3.10.8, SciPy 1.17.1 and Numba 0.64.0.
- The repository does not specify versions for pandas, tqdm or openpyxl.
- Chinese text in plots depends on the configured Chinese fonts being installed on the system; fonts are not Python package dependencies.

### Main files

- [Correlation.py](Correlation.py): correlation analysis.
- [MCM.py](MCM.py): Monte Carlo analysis.
